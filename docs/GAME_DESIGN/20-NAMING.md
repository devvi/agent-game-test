## 1. 命名约束（红线，PRD §5 边界 3）

| 约束 | 值 | 理由 |
|------|-----|------|
| 词数 | 主标题 ≤ 3 词 | 720×1280 竖屏屏显 + 街机利落感（#383 后） |
| 字符数 | 主标题 ≤ 12 字符 | 商店页/标题屏可读性 |
| 生僻词 | 禁止 | 第一眼秒懂优先 |
| 语言 | 主标题英文为主，中文仅作副标题候补 | 全英文 UI 语境（YOU WIN! / AI WINS! / SPACE） |
| 原创性对冲 | 含 "PONG" 的候选：副标题不得缺失或空泛 | 避免"怀旧克隆"标签，副标题承担原创性表达 |
