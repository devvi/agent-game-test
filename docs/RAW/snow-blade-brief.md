# 雪夜大刀 — Grill Me 产出（2026-08-18）

> 中国版像素只狼：抗战题材动作游戏。主角 = 国民党先进分子；敌人 = 日本兵 + 汉奸 Boss。
> 用户审美坐标确认（多轮 Grill Me 产出），注入 game-to-issues 分解。

## 审美坐标
- **参考作品**：《只狼》（拼刀/弹反/架势崩解/处决仪式感）+ 抗战黑白电影/水墨画（雪夜、苍白月、浓重墨色）+ 《地雷战》《铁道游击队》山东乡土叙事（庄稼汉拿起刀的韧性）
- **情感目标**：玩家打完感受到"我赢了一场艰难的仗"——爽快胜利感，不是沉重也不是爽文
- **画面词汇**：雪夜、水墨、黄土、血色、苍白
- **文字质感**：短句、克制、乡土
- **反例**：页游感（光效堆砌/浮夸UI/自动战斗/红点充值）、抗日神剧式夸张、日式武士道美化

## 核心机制决策（用户逐条拍板）
| # | 决策 | 内容 |

| 1 | 武器 | 大刀（重砍+硬直，处决爽感直接） |

| 5 | 精英 | 军曹/刺刀兵；小兵 = 日本兵 |
| 6 | 场景 | 山东农村（雪夜） |
| 7 | MVP 边界 | 音效/存档/升级成长全部推到 v1 |

## 完成定义
- **完整路径**：开场（雪夜山东农村，日军进村）→ 主角抄起大刀 → 第一战（2-3个日本兵，教学：格挡/弹反/士气条）→ 村口汉奸带路队（精英战）→ 汉奸 Boss 战（弹反→破绽→处决）→ 结局（Boss斩杀，村民得救，雪夜中主角望向远方）
- **个人完成标准**：汉奸 Boss 处决特写出现时（雪夜+血色+水墨构图），我知道这游戏成了
- **MVP 时长**：10-15 分钟
