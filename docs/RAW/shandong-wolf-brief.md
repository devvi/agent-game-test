# 山东抗日之狼 — Grill Me 产出（2026-08-18 初版 + 08-19 更新）

> 中国版像素只狼：抗战题材动作游戏。**主角 = 明面国民党、实际八路（双面身份）**；
> 敌人 = 日本兵 + 汉奸 Boss。雪夜山东农村，大刀/弹反/士气条。
> 原名"雪夜大刀"，2026-08-19 定名《山东抗日之狼》，manifest 注册 `shandong-wolf`。

## 审美坐标
- **参考作品**：《只狼》（拼刀/弹反/架势崩解/处决仪式感）+ 抗战黑白电影/水墨画（雪夜、苍白月、浓重墨色）+ 《地雷战》《铁道游击队》山东乡土叙事（庄稼汉拿起刀的韧性）+ 双雪涛小说（冷冽短句、雪与硬汉）
- **情感目标**：玩家打完感受到"我赢了一场艰难的仗"——爽快胜利感，不是沉重也不是爽文
- **画面词汇**：雪夜、水墨、黄土、血色、苍白
- **文字质感**：短句、克制、乡土
- **反例**：页游感（光效堆砌/浮夸UI/自动战斗/红点充值）、抗日神剧式夸张、日式武士道美化

## 主角设定（2026-08-19 更新）
- **明面**：国民党部队成员（身份掩护）
- **实际**：八路军（地下/潜伏）
- 叙事含义：狼的孤独 = **他在两边都"不是自己人"**。身份不能暴露 → 对白话里有话、克制；面具本身就是张力来源
- 影响面：开场设计、对白（B1）、Boss 战戏剧性（背叛者 vs 卧底）、结局表达

## 核心机制决策（用户逐条拍板）
| # | 决策 | 内容 |
|---|------|------|
| 1 | 武器 | 大刀（重砍+硬直，处决爽感直接） |
| 2 | 弹反 | 精准时机格挡 → 敌人硬直；敌人士气条崩解 → 处决（白刃斩特写） |
| 3 | 死亡处理 | 玩家士气槽代替血条：士气崩 = 被俘/任务失败 → 回营地重试；**原地不动喘息回复士气**；敌人也有士气条 |
| 4 | Boss | **汉奸**（军刀 vs 大刀拼刀对决；背叛者比敌人更可恨的叙事张力） |
| 5 | 精英 | 军曹/刺刀兵；小兵 = 日本兵 |
| 6 | 场景 | 山东农村（雪夜） |
| 7 | MVP 边界 | 音效/存档/升级成长全部推到 v1 |

## 完成定义
- **完整路径**：开场（雪夜山东农村，日军进村）→ 主角抄起大刀 → 第一战（2-3个日本兵，教学：格挡/弹反/士气条）→ 村口汉奸带路队（精英战）→ 汉奸 Boss 战（弹反→破绽→处决）→ 结局（Boss斩杀，村民得救，雪夜中主角望向远方）
- **个人完成标准**：汉奸 Boss 处决特写出现时（雪夜+血色+水墨构图），我知道这游戏成了
- **MVP 时长**：10-15 分钟
