## 1. 设计方向总览

**一句话:** 把 Mini Pong 改造成**垂直攻城战肉鸽** — 玩家在底部, 对手在顶部, 中间一道中立砖墙;
球穿过墙洞打进对方底线 = 穿墙分, 击碎砖块 = 拆砖分; 每波砖墙打空一局结束, 3 选 1 升级, 波次递增, 失败即叙事。

**三条设计主线:**
1. **玩法**: Pong(对打反弹) × Breakout(砖墙地形) — 垂直布局, 攻防语义
2. **肉鸽**: 波次递增 + 程序化砖墙 + 3 选 1 升级池 + 失败即叙事
3. **画面**: 雨夜竞技场 — 动态雨量是情绪仪表盘, 霓虹描边 UI, 克制优先

## 2. 布局与玩法(已确认)

```
┌──────────────────────────┐
│ AI 守城 (顶部挡板, 水平移动) │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ ← AI 底线 (穿墙得分目标)
│  ██  ███  █ ██  ███ ██  │ ← 中立砖墙 (横跨, 程序化留缝/错位)
│    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓    │ ← 你开的洞 (雨和球同穿)
│ 玩家攻城 (底部挡板, 水平移动) │
└──────────────────────────┘
```

### 2.1 核心循环

```
波次开始 → 生成中立砖墙(程序化) → 对打:
  玩家(底) 球向上打, 碰砖 → 砖碎(拆砖分给最后触球方) + 反弹
  球穿过墙洞 → 到达 AI 底线 = 穿墙高分
  AI(顶) 同样向下打, 穿洞 → 你的底线 = AI 得分
  砖墙打空 = 一局结束 → 结算 → 3选1升级 → 下一波(墙更厚 + AI更强)
  失败 = 比分落后到阈值 → 叙事碎片 → 重来
```

### 2.2 双得分制(已确认)

| 得分 | 分值 | 触发 | 归属 |
|------|:---:|------|------|
| 拆砖分 | 1 | 球击碎砖块 | **最后触球方** (竞争拆墙, 已确认) |
| 穿墙分 | 3 | 球穿过墙洞到达对方底线 | 攻击方 (击穿是稀缺高价值动作) |

### 2.3 砖墙语义(中立, 已确认)

- 砖块 = **可破坏的反弹地形**: 球碰砖 → 砖碎 + 反弹 (Breakout 式)
- 洞口 = **无碰撞通道**: 球直飞 (穿墙得分路径)
- 砖墙打空 = 一局结束
- 程序生成: 非均匀网格, 留缝/错位/局部缺口 — "一道被反复击打过的旧墙"

### 2.4 失败条件(默认, 待最终确认)

- 比分制: AI 先到 N 分 = 波失败 (拆砖分/穿墙分都算比分)

### 2.5 升级池(纯数值, 已确认)

3 选 1, 每波一选:

| 类别 | 升级示例 | 落地 |
|------|---------|------|
| 球系 | 穿透+1层 / 分裂球 / 弧线球 / 球速+10% | ball 实例参数 + 工厂 |
| 板系 | 挡板+30% / 移速+ / 磁力吸球 | paddle 尺寸实例化 |
| 墙系 | 破砖冲击波(碎邻近砖) / 开局预开一洞 | 砖墙系统 |
| 时间 | 缓速 2s / 双球 | GameManager run 状态 |

## 3. 画面方案: 雨夜竞技场(已确认)

### 3.1 分层架构 (4 层 CanvasLayer)

```
L0 氛围层: 雨幕粒子 + 底部城市光晕 + 暗角(≤10%)
L1 世界层: 砖墙(发光+破洞) + 球/挡板/拖尾
L2 反馈层: 破砖闪光/穿墙脉冲/得分弹出/挡板 squash
L3 UI层:  HUD/升级卡/波次转场/失败屏
```

### 3.2 动态雨量 (已确认 — 雨是情绪仪表盘)

```
rain = base(0.3) + 球速因子 + 波次因子(+0.1/波) + 紧张因子(比分差≤2 → +0.2)
     + 事件脉冲(穿墙 → +0.4 回落; 失败 → 1.0) − 喘息窗口(升级选择 → 0.15)
clamp(0.1, 1.0)
```

| 情境 | 雨量 | 情绪 |
|------|:---:|------|
| 波次开始 | 0.3 | 平静开场 |
| 球速上升 | 0.4→0.6 | 紧张积累 |
| 比分胶着 | 0.7 | 窒息 |
| 穿墙得分 | 0.9 脉冲 | 爆发 |
| 升级选择 | 0.15 | 喘息 |
| 波失败 | 1.0 | 宣泄 |

映射规则 = **机械**(可测); 浓度曲线 = **taste-draft**(人调)。

### 3.3 UI (已确认)

- 字体: 默认字体 + 霓虹描边 + 微投影 (headless 安全, 零 license 成本)
- HUD: 顶部中央 拆砖分/穿墙分 双区 + 波次号 + 剩余砖数; 玩家蓝/AI 红
- 升级卡: 3 张霓虹卡片, glow 边框 + hover 微亮, 数值大字
- 波次转场: 大字「第三道墙」+ 海明威式副句, 2s
- 失败屏: 短句为主 + run 数据 (波次/拆砖/穿墙)
- 动效: 统一 Tween 淡入/滑入 (150-300ms), 不弹跳不花哨

- **完成路径**: MENU → 波1 (教学薄墙) → 3选1 → 波2 → ... → 失败屏(短句+run数据) → MENU

- **验证**: 自动对打测试 (AI vs AI 全波次) + E2E 截图 (砖墙/雨幕/升级卡/失败屏)
