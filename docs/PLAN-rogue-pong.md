# Rogue Pong — 攻城战肉鸽化方案(正式版)

> 状态: **已确认** (2026-08-13, 用户拍板)
> 前置事实: v4 人机共做闭环已验证 (#367 A1 手感定稿 → TASTE.md v1; #378 B2 命名定稿 → PONG://NEON)
> 输入: 玩法讨论 5 轮 (变体选型→中立墙→双得分→垂直布局→雨夜氛围)

---

## 1. 设计方向总览

**一句话:** 把 Mini Pong 改造成**垂直攻城战肉鸽** — 玩家在底部, 对手在顶部, 中间一道中立砖墙;
球穿过墙洞打进对方底线 = 穿墙分, 击碎砖块 = 拆砖分; 每波砖墙打空一局结束, 3 选 1 升级, 波次递增, 失败即叙事。

**三条设计主线:**
1. **玩法**: Pong(对打反弹) × Breakout(砖墙地形) — 垂直布局, 攻防语义
2. **肉鸽**: 波次递增 + 程序化砖墙 + 3 选 1 升级池 + 失败即叙事
3. **画面**: 雨夜竞技场 — 动态雨量是情绪仪表盘, 霓虹描边 UI, 克制优先

## 2. 布局与玩法(已确认)

```
┌──────────────────────────┐
│ AI 守城 (顶部挡板, 水平移动) │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ ← AI 底线 (穿墙得分目标)
│  ██  ███  █ ██  ███ ██  │ ← 中立砖墙 (横跨, 程序化留缝/错位)
│    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓    │ ← 你开的洞 (雨和球同穿)
│ 玩家攻城 (底部挡板, 水平移动) │
└──────────────────────────┘
```

### 2.1 核心循环

```
波次开始 → 生成中立砖墙(程序化) → 对打:
  玩家(底) 球向上打, 碰砖 → 砖碎(拆砖分给最后触球方) + 反弹
  球穿过墙洞 → 到达 AI 底线 = 穿墙高分
  AI(顶) 同样向下打, 穿洞 → 你的底线 = AI 得分
  砖墙打空 = 一局结束 → 结算 → 3选1升级 → 下一波(墙更厚 + AI更强)
  失败 = 比分落后到阈值 → 叙事碎片 → 重来
```

### 2.2 双得分制(已确认)

| 得分 | 分值 | 触发 | 归属 |
|------|:---:|------|------|
| 拆砖分 | 1 | 球击碎砖块 | **最后触球方** (竞争拆墙, 已确认) |
| 穿墙分 | 3 | 球穿过墙洞到达对方底线 | 攻击方 (击穿是稀缺高价值动作) |

### 2.3 砖墙语义(中立, 已确认)

- 砖块 = **可破坏的反弹地形**: 球碰砖 → 砖碎 + 反弹 (Breakout 式)
- 洞口 = **无碰撞通道**: 球直飞 (穿墙得分路径)
- 砖墙打空 = 一局结束
- 程序生成: 非均匀网格, 留缝/错位/局部缺口 — "一道被反复击打过的旧墙"

### 2.4 胜负判定(21 分制, 已确认 2026-08-13)

- **整场先到 21 分者赢**: 对手(AI)先到 21 → 玩家输; 玩家先到 21 → 玩家赢
- 砖墙打空 = 升级 + 新墙, 比赛继续, 直到有人到 21 分
- 拆砖分(1) + 穿墙分(3) 都计入比分
- 节奏: 21 分制拉长单局, 升级次数更多, 情绪曲线完整 (约 5-8 次有效攻击 → 一次升级, 全场 3-5 次升级窗口)

### 2.5 升级池 — 情绪化设计 (体验引擎, 已确认 2026-08-13)

> 理论依据 (Obsidian): 《体验引擎》情感模型 — 情感源于**人类价值在两极端间变化**, 变化幅度越大越频繁情感越强烈;
> **情感误归因** — 玩家把情绪归因于最显眼的诱因, 允许把"打得爽"转移到升级选择上;
> **可预测奖励变得无聊** — 3 选 1 + 稀有度 = 不可预测性;
> 极乐迪斯科 — 失败生产文学时刻, 带代价的选择更难忘。

**升级池结构 (每波 3 选 1, 带稀有度):**

| 稀有度 | 出现率 | 特征 | 情感角色 |
|--------|:---:|------|---------|
| 普通 | 60% | 纯数值增强 | 稳定掌控感 (技能/无能极) |
| 稀有 | 30% | 数值 + 规则变化 | 惊喜 (预期违背) |
| 传说 | 10% | 改变游戏方式 | 高潮 (支配感) |

**情绪化升级清单 (草案, 含情感断言):**

| 升级 | 稀有度 | 效果 (纯数值) | 情感断言 | 价值极 |
|------|:---:|------|---------|--------|
| 长臂 | 普通 | 挡板 +30% | 安全感 — "够得着" | 安全/危险 |
| 燃烧弹 | 普通 | 球速 +10%, 破砖烧碎相邻 2 块 | 破坏欲 — 拆墙越来越爽 | 破坏/受阻 |
| 破城锤 | 普通 | 破砖冲击波 (碎邻近砖) | 暴力释放 — 一击碎一片 | 破坏/受阻 |
| 磁心 | 稀有 | 挡板磁力吸球 | 掌控感 — 球听你的 | 技能/无能 |
| 双生 | 稀有 | 球分裂为 2 | 兴奋 — 场面失控但归你 | 秩序/混沌 |
| 缓时 | 稀有 | 球速冻结 2s | 时间主宰 — 世界等你 | 快/慢 |
| 预开洞 | 稀有 | 开局自动在墙上开一洞 | 先手优势 — 棋高一着 | 主动/被动 |
| 星尘 | 传说 | 穿墙后留 2s 轨迹伤害 | 支配感 — 全场都是你的痕迹 | 支配/服从 |
| 幻影 | 传说 | 挡板残影多段判定 | 敏捷快感 — 快得看不清 | 敏捷/笨拙 |

**情绪化机制 (体验引擎落地):**
1. **情感误归因**: 每次升级后 2s 内若有得分, 得分数字带上升级图标 — 把"我打得好"归因到"我选得好"
2. **不可预测奖励**: 3 选 1 卡片稀有度不提前显示, 选择后才 reveal (惊喜时刻)
3. **带代价的选择** (极乐迪斯科式): 传说升级可选但带代价 (如"球速+20% 但挡板 -10%") — 选择本身生产紧张
4. **升级短句**: 每张卡一行克制短句 (B5 领域, 人定稿) — "长臂: 够得着了" / "双生: 分身"

## 3. 画面方案: 雨夜竞技场(已确认)

### 3.1 分层架构 (4 层 CanvasLayer)

```
L0 氛围层: 雨幕粒子 + 底部城市光晕 + 暗角(≤10%)
L1 世界层: 砖墙(发光+破洞) + 球/挡板/拖尾
L2 反馈层: 破砖闪光/穿墙脉冲/得分弹出/挡板 squash
L3 UI层:  HUD/升级卡/波次转场/失败屏
```

### 3.2 动态雨量 (已确认 — 雨是情绪仪表盘)

```
rain = base(0.3) + 球速因子 + 波次因子(+0.1/波) + 紧张因子(比分差≤2 → +0.2)
     + 事件脉冲(穿墙 → +0.4 回落; 失败 → 1.0) − 喘息窗口(升级选择 → 0.15)
clamp(0.1, 1.0)
```

| 情境 | 雨量 | 情绪 |
|------|:---:|------|
| 波次开始 | 0.3 | 平静开场 |
| 球速上升 | 0.4→0.6 | 紧张积累 |
| 比分胶着 | 0.7 | 窒息 |
| 穿墙得分 | 0.9 脉冲 | 爆发 |
| 升级选择 | 0.15 | 喘息 |
| 波失败 | 1.0 | 宣泄 |

映射规则 = **机械**(可测); 浓度曲线 = **taste-draft**(人调)。

### 3.3 UI (已确认)

- 字体: 默认字体 + 霓虹描边 + 微投影 (headless 安全, 零 license 成本)
- HUD: 顶部中央 拆砖分/穿墙分 双区 + 波次号 + 剩余砖数; 玩家蓝/AI 红
- 升级卡: 3 张霓虹卡片, glow 边框 + hover 微亮, 数值大字
- 波次转场: 大字「第三道墙」+ 海明威式副句, 2s
- 失败屏: 短句为主 + run 数据 (波次/拆砖/穿墙)
- 动效: 统一 Tween 淡入/滑入 (150-300ms), 不弹跳不花哨
