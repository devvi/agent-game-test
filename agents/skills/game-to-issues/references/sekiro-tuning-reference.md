## 手感铁律（从只狼提炼，写进 AC）

1. **弹反成功必须比格挡爽**：火花 + hit-stop + 敌人硬直 1.2s 窗口（可安全输出）
2. **架势崩解必须惩罚清晰**：失衡硬直 2-3s + 白闪，玩家可从容处决
3. **两条命不是两条血**：第一条命允许失误（硬汉），第二条半血是"最后一搏"（紧张）——死亡成本曲线
4. **架势回复是节奏阀**：回复太快=无脑弹反，太慢=龟缩。基准 20-35/s 保"弹-挡-喘息"节奏
5. **处决是奖励不是补刀**：架势崩解后处决 = 演出（hit-stop + 特写），不崩解也能磨死但慢
6. **受击惩罚双重**（扣血+扣架势）——纯防御会崩架势，逼玩家进攻（只狼核心哲学）

## 调参优先级（#13 调参面板）

第一优先级（影响最大）：弹反窗口、架势回复速度、受击扣架势
第二优先级：敌人攻击前摇、轻/重击架势伤害
第三优先级：两条命血量、处决窗口、慢动作系数
