Implement the Mysterious Stranger NPC Framework (#223) for this Godot 4.7.1 game.

## Context: Codebase patterns
- Scene scripts extend `SceneBase` and use `@onready` vars for nodes, `scene_id = "..."`, `super._ready()`
- Dialogue uses godot_dialogue_manager `.dialogue` format with `using StateSystem` header
- DialogueParser.load_dialogue(path) strips "using" and "#" header lines, then parses rest as JSON
  - If content is NOT JSON after stripping headers, parse fails — so NEW .dialogue files MUST be JSON
- `start_dialogue()` is from SceneBase, calls _show_dialogue_balloon()
- NarrativeManager is an autoload at /root/NarrativeManager
- SceneBase is at gdscripts/scene_base.gd

## Files to MODIFY (script files):

### Modify: gdscripts/narrative_manager.gd
ADD the following 3 NEW methods (do NOT modify existing methods):

1. `static func get_hallucination_variant(scene_id: String, base_count: int = 3) -> int:`
   - Uses HALLUCINATION_BASE_LEVELS to look up the scene's base hallucination level
   - Returns 0 if base level is 0-3 (low hallucination)
   - Returns 1 if base level is 4-6 (mid hallucination)
   - Returns 2 if base level is 7-10 (high hallucination)
   - The second parameter `base_count` is ignored — the method always uses HALLUCINATION_BASE_LEVELS
   - Must be `static` because the test calls it without instantiation

2. `static func get_stranger_decal_color(hallucination_level: int) -> Color:`
   - Maps level (0-10) to a Color using a 5-index gradient:
     - index 0 (level 0-1): Color(0.5, 0.7, 1.0, 0.3) — blue-tinted, faint
     - index 1 (level 2-3): Color(0.3, 0.8, 1.0, 0.4) — cyan
     - index 2 (level 4-5): Color(1.0, 1.0, 1.0, 0.5) — white
     - index 3 (level 6-7): Color(1.0, 0.7, 0.3, 0.5) — orange
     - index 4 (level 8-10): Color(1.0, 0.2, 0.2, 0.6) — red-tinted
   - Use `clampi(hallucination_level / 2, 0, 4)` for the index
   - Must handle out-of-bounds (negative, >10) gracefully via clampi
   - Must be static

3. `func get_scene_stranger_flags(scene_id: String) -> Dictionary:`
   - Returns a Dictionary with all Stranger-related flags for the given scene
   - Access flags via `_game_manager` or `_state_system`
   - Return format: {flag_name: bool_value}
   - NOT static — may need _game_manager reference
   - If no game_manager available, return empty Dictionary (no crash)
